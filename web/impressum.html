Über dieses Projekt

Kaufland Extra Finder ist ein privates, nicht-kommerzielles Open-Source-Projekt. Es gibt keine Werbung, keine Bezahlinhalte und keine Benutzerkonten; der gesamte Quellcode ist öffentlich auf GitHub einsehbar.

Wer das Projekt unterstützen möchte, kann das freiwillig über GitHub Sponsors tun. Eine Unterstützung ist keine Gegenleistung für Inhalte oder Funktionen; die Website bleibt für alle gleich und kostenlos.

Das Projekt steht in keiner Verbindung zu Kaufland oder zu anderen Unternehmen der Schwarz Gruppe und wird von diesen weder unterstützt noch geprüft. „Kaufland“ ist eine Marke ihrer jeweiligen Inhaberin.

Haftung für Inhalte

Die angezeigten Filial- und Prospektdaten werden automatisch von öffentlich zugänglichen Webseiten von Kaufland gelesen und mehrmals pro Woche aktualisiert. Sie können unvollständig, veraltet oder fehlerhaft sein. Alle Angaben erfolgen ohne Gewähr; maßgeblich ist ausschließlich der Prospekt der jeweiligen Filiale.

Haftung für Links

Diese Website verlinkt auf Webseiten Dritter, insbesondere auf Prospekte und Filialseiten von Kaufland. Auf deren Inhalte habe ich keinen Einfluss; für sie ist der jeweilige Anbieter verantwortlich. Bei Bekanntwerden von Rechtsverletzungen entferne ich entsprechende Links umgehend.
